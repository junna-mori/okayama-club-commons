# COMMONS · Okayama Student Guide

留学生と日本人学生が、部活動と食を通じてつながるための日本語・英語サイトです。初期表示は英語、配色は企画資料の濃紺 `#182053`・黄色 `#F4C44D` を使用しています。COMMONSは制作上の仮称です。外部公開・GitHubへのアップロードは行っていません。

第2版では、大学案内のようなヘッダー・案内メニュー・文字組みに変更し、ホーム1点、部活動8点、食事候補5点の生成画像を配置しました。岡山大学公式とは表示せず、大学章や大学のロゴも使用していません。

## 最初に見るファイル

- `docs/HANDOFF_JA.md`：次に担当する人・AI向けの引き継ぎメモ
- `docs/CONTENT_SOURCES.md`：掲載情報の根拠、確認済み・未確認の区別
- `docs/DEPLOYMENT.md`：GitHub・Vercel・GitHub Pagesの公開手順
- `docs/QA.md`：実施した確認と残る確認事項
- `docs/ASSETS.md`：生成画像の一覧と扱い
- `docs/IMAGE_PROMPTS.json`：各画像の生成・調整プロンプト

## 起動

見た目を手軽に確認する場合は、`OPEN_PREVIEW.html` をブラウザで開いてください。画像・CSS・JavaScriptを埋め込んだ、確認用の単独HTMLです。開発や公開には下の手順を使います。元ファイルを変更したら `npm run export-preview` で確認用HTMLも更新してください。

Node.js 20以降があれば、追加のライブラリやAPIキーは不要です。

```sh
npm run dev
```

表示されたローカルURLをブラウザで開きます。通常は `http://127.0.0.1:4173` です。終了は `Ctrl+C`。開発用の `index.html` はダブルクリックではES Modulesの読み込みが制限されるため、HTTPサーバー経由で開きます。単独の `OPEN_PREVIEW.html` は画像等を埋め込んでおり、この制約を避けています。

## 検証・ビルド

```sh
npm run check
npm run build
npm run preview
```

`dist/` が公開用フォルダーです。ビルドでコピーされるのはサイト用ファイルだけです。資料PPTX、作業用ファイル、手順書は公開用フォルダーに入りません。`npm install` は不要です。

## 技術上の前提

HTML / CSS / JavaScript（ES Modules）の静的サイトです。React、Next.js、データベース、ログイン、サーバー側APIに依存しません。URLは `#/clubs` のようなハッシュルートなので、Vercel・GitHub Pagesのどちらでも専用のルーティング設定なしで表示できます。

言語は `?lang=en` または `?lang=ja` で指定できます。指定がなければ前回の選択を使い、初めてのアクセスは英語です。ブラウザ保存は言語と部活動IDのみです。相談文の入力情報は外部送信・永続保存しません。外部フォント・アクセス解析・広告は使用していません。

## 公開に向けて

現在は `noindex,nofollow` と `robots.txt` の巡回拒否を設定しています。**これは閲覧のアクセス制限ではありません**。一般公開と検索掲載を決めたら、運営者・団体・店舗の情報を確認したうえで変更してください。

提供資料の人物写真・個人名・本人による直接引用は掲載していません。仮称、運営主体、連絡先、実際の写真の掲載可否は未確定です。各部の留学生の参加条件、店舗の営業・食事対応は、公開情報を調べた段階です。実際の受け入れ・注文前には本人と団体・店舗との確認が必要です。
